# IKE K VENTURES — Website

Informational website for **IKE K VENTURES**, an Over-the-Counter (OTC) medicine seller located directly opposite Apremdo Market on Apremdo Road (off the 2BN Garrison Main Road), Takoradi, Ghana.

## Tech Stack
- **HTML5** ([`index.html`](index.html)) — Semantic structure, accessibility roles, and LocalBusiness schema.
- **CSS3** ([`css/styles.css`](css/styles.css)) — Mobile-first responsive styling using the 60–30–10 Cool Blue-Gray, Deep Navy, and Pharmacy Teal palette.
- **Vanilla JavaScript** ([`js/main.js`](js/main.js)) — Ghana GMT (`UTC+0`) live open/closed indicator, mobile navigation toggle, and staff shift phone number rotation config.

## Running Locally
Run a lightweight static server from the project root:

```bash
python3 -m http.server 5050
```

Then open `http://localhost:5050` in your browser.
